# Андрей М. — Консультант по банковским продуктам

Современный минималистичный сайт-визитка для консультанта по банковским продуктам.

## 🎨 Дизайн

- **Темный минималистичный дизайн** — полностью черный фон
- **Эффект курсора** — светящаяся область вокруг курсора (только на desktop)
- **Glassmorphism** — размытые полупрозрачные плашки
- **Бегущие строки** — анимированные разделители между секциями
- **Градиентные акценты** — cyan и green на ключевых элементах
- **Адаптивная верстка** — оптимизировано для всех устройств

## 🛠️ Запуск локально

1. Клонируйте репозиторий
2. Откройте `index.html` в браузере

Или используйте локальный сервер:

```bash
# Python
python -m http.server 8000

# Node.js
npx serve
```

## 📱 Адаптивность

- **Desktop**: 1024px и выше
- **Tablet**: 768px - 1023px
- **Mobile**: до 767px
- **Small Mobile**: до 480px
